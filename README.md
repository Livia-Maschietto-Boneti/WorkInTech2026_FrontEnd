# 🚀 Meu Currículo | Web Fundamentos 2026
💻 Do zero ao primeiro portfólio — transformando código em oportunidades!

Projeto desenvolvido durante o workshop Web Fundamentos · Working Tech 2026, da Unicesumar, com foco nos fundamentos do desenvolvimento web.

# ✨ Sobre o projeto

Um portfólio pessoal criado para colocar em prática os conhecimentos de HTML5, CSS3 e JavaScript, unindo design, interatividade e responsividade em um só lugar, ensinado pelo profissional Paulo Ricardo.

🎯 Funcionalidades
🏠 Apresentação pessoal com foto, nome e profissão.
🙋 Sobre mim e minhas habilidades.
🛠️ Tecnologias apresentadas com ícones.
🎠 Carrossel de projetos com navegação por setas.
✉️ Formulário de contato interativo.
🌗 Tema claro e escuro com alternância por clique.
# 🧰 Tecnologias utilizadas

HTML5 · CSS3 · JavaScript · Git · GitHub

# 🌱 Aprendizados

Na prática, explorei a estruturação de páginas, estilização responsiva, manipulação do DOM, eventos JavaScript e versionamento de código com Git e GitHub.
